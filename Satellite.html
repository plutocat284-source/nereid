3축 자세 제어 계산 로직

1. 관성모멘트

위성을 균일한 직육면체로 가정하고 사용자가 입력한 질량과 크기로 각 주축 관성모멘트를 계산합니다.

Ixx = m(y² + z²)/12　 Iyy = m(x² + z²)/12　 Izz = m(x² + y²)/12

2. 궤도 운동과 외력

v = √(μ/r)　 g = μ/r²　 T = 2π√(r³/μ)
Fdrag = ½ρv²CdA　 Fsolar = PsolarCrA

중력은 지구 중심 방향, 항력은 공전 속도 반대 방향, 태양 복사압은 태양에서 멀어지는 방향으로 표시합니다.

3. 3축 자세 운동

Ixx·αx = τx　 Iyy·αy = τy　 Izz·αz = τz

각 축에서 환경 토크와 제어 토크를 더해 각가속도를 계산하고, 시간에 따라 각속도와 자세각을 갱신합니다.

4. 자동 자세 제어

τcontrol = Kp·(목표각 − 현재각) − Kd·각속도

각 축에 독립적인 PD 형태의 제어기를 적용합니다. 자동 제어를 끄면 사용자가 입력한 X·Y·Z 수동 토크가 적용됩니다.

5. 교육용 모델의 한계

실제 위성은 3차원 회전축 사이의 결합, 센서 측정 오차, 반작용 휠의 각운동량 변화, 자기토커 및 추진기 특성 등을 함께 고려합니다. 이 프로그램은 기본 원리를 살펴보기 위한 축별 단순 모델입니다.
