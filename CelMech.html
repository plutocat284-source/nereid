시뮬레이터 계산 로직

1. 뉴턴의 만유인력 법칙

질량이 있는 두 천체는 서로를 끌어당깁니다. 힘의 크기는 두 질량의 곱에 비례하고, 두 천체 사이 거리의 제곱에 반비례합니다.

F = G · (m₁m₂ / r²)

여기서 G는 만유인력 상수(6.67430 × 10⁻¹¹ N·m²/kg²), m₁과 m₂는 각 천체의 질량(kg), r은 두 천체 중심 사이 거리(m)입니다. 두 천체에 작용하는 힘은 크기가 같고 방향은 서로 반대입니다.

2. 중력의 방향과 중력 가속도

a₁ = F₁₂ / m₁,　a₂ = F₂₁ / m₂

각 천체의 가속도 방향은 상대 천체를 향합니다. 시뮬레이터는 모든 천체 쌍(항성-항성, 항성-행성, 행성-행성)에 대해 힘을 계산하고, 각 천체의 가속도를 합산합니다.

3. N체 운동 방정식

d²rᵢ/dt² = Σⱼ≠ᵢ Gmⱼ (rⱼ-rᵢ) / |rⱼ-rᵢ|³

한 천체에 작용하는 전체 중력 가속도는 나머지 모든 천체가 만드는 가속도의 벡터합입니다. 따라서 행성이 여러 개이면 행성끼리의 중력도 각 행성의 운동에 영향을 줍니다.

4. 수치 적분: 속도-위치 베르레 방법

r(t+Δt) = r(t) + v(t)Δt + ½a(t)Δt²
v(t+Δt) = v(t) + ½[a(t)+a(t+Δt)]Δt

현재 위치와 가속도로 다음 위치를 구한 뒤, 새 위치에서 가속도를 다시 계산합니다. 이전과 다음 가속도의 평균을 사용해 속도를 갱신합니다. 이 방식은 천체 운동처럼 장시간 누적되는 역학 계산에 활용되는 적분법입니다.

5. 초기 원궤도 속도

v = √(G(M+m)/r)

새 행성을 배치할 때 가장 가까운 항성을 기준으로 원궤도에 가까운 초기 접선 방향 속도를 부여합니다. 여기서 M은 항성 질량, m은 행성 질량, r은 두 천체 사이 거리입니다. 다른 천체가 존재하면 실제 궤도는 원형에서 벗어날 수 있습니다.

6. 타원궤도 설정

rₚ = a(1-e),　vₚ = √[μ(1+e)/(a(1-e))]

a는 궤도 반장축, e는 이심률, μ=G(M+m)입니다. 입력한 반장축과 이심률을 이용해 근일점 위치와 근일점 속도를 설정합니다. e=0이면 원궤도이며, 0<e<1이면 타원궤도입니다.

7. 사용 단위와 근사

내부 운동 계산은 AU(천문단위), M☉(태양질량), 년을 사용하며 G=4π² AU³/(M☉·년²)로 둡니다. 힘을 뉴턴(N)으로 표시할 때는 SI 단위로 변환합니다. 천체의 화면상 크기는 실제 반지름 비율이 아닌 시각적 표현이며, 계산은 교육용 2차원 뉴턴 역학 모델입니다.
